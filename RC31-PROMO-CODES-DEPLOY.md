# RC31 — керування промокодами

## Що завантажити на GitHub
Завантажте весь вміст архіву як звичайне оновлення сайту.

## Що виконати в Supabase
1. SQL Editor → New query → вставте та виконайте `supabase/migrations/20260726_promo_codes.sql`.
2. Edge Functions → розгорніть нову функцію `validate-promo` з `supabase/functions/validate-promo/index.ts`.
3. Повторно розгорніть `create-order` з `supabase/functions/create-order/index.ts`.

## Де керувати
`/admin/` → вкладка **Промокоди**.

## Можливості
- фіксована знижка;
- відсоткова знижка;
- безкоштовна доставка;
- мінімальна сума;
- дата старту та завершення;
- загальний ліміт використань;
- усі товари, усі аромадифузори або конкретні ID товарів;
- миттєве увімкнення/вимкнення.

Початковий код `TEST` створюється автоматично: −100 грн на повноцінний аромадифузор.
