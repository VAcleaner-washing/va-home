# VA HOME v13.6.9 — перед публікацією

## Статичний сайт

Завантажте вміст архіву в корінь сайту. Усі CSS/JS-ресурси мають query-version `13.6.9`.

У цій версії всі 15 зображень Journal зведені в одну editorial-серію VA HOME: 11 атмосферних і процесних кадрів без продукту та 4 продуктові кадри лише для матеріалів, де флакон є частиною теми. Зображення мають розмір `1672 × 941`, а обкладинки, картки та hero-блоки статей використовують ті самі файли.

## Supabase Edge Function

Перед публікацією оновленої `create-order` додайте в Supabase Secrets:

- `PAYMENT_RECIPIENT` — отримувач платежу;
- `PAYMENT_IBAN` — рахунок для оплати.

Значення не слід зберігати в GitHub або у фронтенд-файлах.

Порядок безпечного оновлення:

1. Додати обидва secrets.
2. Опублікувати `supabase/functions/create-order/index.ts`.
3. Опублікувати статичний сайт.
4. Оформити два тестові замовлення: банківський переказ і післяплата.
5. Перевірити лист клієнту, сторінку `thank-you.html` і запис у таблиці `orders`.

`discovery-17` залишено лише як перехідний alias для сумісності зі старими кошиками та попередньою Edge Function. Канонічний ID на сайті — `discovery-18`.
