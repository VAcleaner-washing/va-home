# RC26 — Nova Poshta search UX

- Mobile Safari and installed PWA now use a compact anchored result panel instead of a large floating bottom sheet.
- The panel follows the active input and fits inside the current visual viewport above the keyboard/browser controls.
- Desktop results always reset to the first match. Exact warehouse numbers are ranked first.
- Selecting a result closes the mobile keyboard.
- No additional Supabase deploy is required beyond the RC22/RC23 functions.
