# RC33 — Promo switch scroll fix

Виправлено стрибок модального вікна промокоду після вимкнення перемикачів **Без обмеження** та **Без дати завершення**.

Причина: невидимі checkbox-елементи мали `position:absolute`, але не були прив’язані до контейнера перемикача. Браузер міг прокручувати модальне вікно до фактичної позиції прихованого елемента.

Що змінено:
- контейнер перемикача отримав `position: relative`;
- прихований checkbox тепер лежить точно поверх видимого треку;
- під час зміни стану зберігається внутрішня позиція прокрутки форми.

Потрібно лише оновити файли сайту на GitHub. SQL та Edge Functions повторно розгортати не потрібно.
