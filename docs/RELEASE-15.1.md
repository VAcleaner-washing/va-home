# VA HOME 15.1.0

## 2. Відгуки та AggregateRating

У product HTML пререндерено всі 8 схвалених відгуків, які були в Supabase на
момент збірки. Pure Zen і Pure Imagination більше не залежать від JavaScript,
щоб показати перший відгук Google. Product schema містить `aggregateRating` і
`review` лише там, де є реальний схвалений відгук.

Оновлення повторюється командами:

```text
npm run build:reviews
```

За потреби перед цим свіжий публічний snapshot отримується через
`scripts/fetch-review-seo-snapshot.mjs`.

## 3. Категорійні посадкові

Додано 5 окремих комерційних сторінок:

- аромадифузори для спальні;
- аромадифузори для вітальні;
- аромадифузори для ванної;
- подарункові аромадифузори;
- готельні аромати для дому.

Це не дублікати Journal. Кожна сторінка містить добірку товарів із ціною й
кнопкою кошика, ItemList, FAQ, canonical та контекстне посилання на відповідний
матеріал Journal.

## 4. Адаптивні зображення

Для 32 ключових джерел створюються варіанти 640, 960 і 1280 px у WebP та AVIF.
Затверджені кадри не змінюються й не генеруються повторно — оптимізується лише
розмір файлу. На контрольній вибірці мобільний WebP 640 px легший за сукупність
оригіналів приблизно на 81%, AVIF — приблизно на 90%.

Pipeline:

```text
npm ci
npm run build:images
```

## 5. Supabase migrations та RLS

У `supabase/production-migrations.json` зафіксовано всі 20 production
міграцій. У `PRODUCTION-SCHEMA-BASELINE.md` збережено перевірений стан 15
public-таблиць, RLS і scope функцій.

Старі remote-only міграції не відтворювалися приблизним SQL. Це свідоме
рішення: фальшива історія небезпечніша за чесно позначений baseline. Починаючи
з 15.1, кожна зміна БД має окремий timestamped migration-файл і проходить
перевірку RLS/grants до production.
